# Late Night Loops

A responsive and interactive music website built with HTML, CSS, and JavaScript, showcasing curated tracks across genres with an immersive browsing experience.

## Features

* Genre-based navigation with animated transitions
* Engaging visual design and hover effects
* Responsive layout optimized for various devices
* SEO-friendly metadata
* Accessible from: [late-night-loops.vercel.app](https://late-night-loops.vercel.app/home/home.html)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sallylijiaxuan/late-night-loops.git
cd late-night-loops
```

2. Open `home/home.html` in your browser to explore the site locally.

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Deployed via Vercel
